# 前端（仅Ubuntu/Linux开发与验收）
> 本文保留历史合同或验收记录；原始报告、截图、JAR及未公开合同不随公开源码发布，文中历史结论不代表当前版本验收。

React19、TypeScript、Vite8、Ant Design6、Tailwind4、Lucide、Motion及Zustand5；公共Button、表格、抽屉与树沿现有组件入口复用。应用构建和运行仅支持Ubuntu/Linux，Ubuntu24.04 LTS amd64为当前目标。管理端/客户侧保留独立受众、显式单位与逐请求权限边界。

## 开发与构建

在Ubuntu安装Node24，或从工程根目录准备项目本地工具后使用统一入口：

```bash
bash scripts/prepare-tools.sh
bash scripts/verify.sh
bash scripts/package.sh --skip-install
```

已有Node24在PATH时也可在前端目录独立操作：

```bash
cd frontend
npm ci
npm test
npm run build
npm run dev -- --host 127.0.0.1
```

开发模式使用既有Vite代理及后端API配置；正式打包由根脚本把dist嵌入Java21后端，不部署常驻Node/Vite服务。输出与依赖都是生成物，不复制宿主node_modules到Ubuntu；不同系统的原生构建依赖必须重新`npm ci`。
开发代理默认允许本机主机名和 IP；确需经可信测试域名访问时，用 `__VITE_ADDITIONAL_SERVER_ALLOWED_HOSTS` 指定该域名，不开放整个后缀。

## 原业务与页面边界

- 设备台账、筛选工作台、位置和海康发现页的「查看详情」切换到同一双栏详情，返回保留上级筛选。左栏设备资料、监测值和设备控制；右栏报警、故障、事件、在离线、远程参数和生命周期。时间来源不明不补值；海康登记状态和平台离线判定分开。控制和参数使用已有命令队列、型号能力凭据、权限、命令确认和回执；没有已核验的「禁用」能力时不以屏蔽或远程停机替代。
- 设备列表和详情使用接口的 `status_display`，不在浏览器重算在线状态。`UNKNOWN` 显示为“状态未确认”，不是离线；如果已有未处理火警等业务状态，连接未确认不会覆盖它。
- 管理业务页默认展示全部已授权单位，独立树栏初始全选；单位与位置子树取并集，清空显示未选择范围，不回退为全部。共享选择跨页保留、变化销毁旧读与草稿；个人中心保持本人语义。汇总读取不带全局单位头，详情/写入必须取记录 `tenant_id` 或操作内明确选定的单位，不借树筛选授予权限。强制改密、身份generation、当前grant/权限、page/op/signal及完整body前后owner屏障仍有效，旧响应不得影响新owner。
- 报警变更/通道/用户选择有限重连仍独立C/T/W，不自动HTTP补拉、实体patch或默认连接。
- 最小审计仅显式管理读；客户不因伪权限得到入口。安全分类与三态引用不显示raw路径/body/凭据。
- 设备分组双端现device:read查看，PLATFORM device:write经明确二次确认维护；多对多不授权、不改设备事实。未知结果保留canonical key/原意图，409资格不因关闭重开恢复，只显式刷新；成功只收据，不自动GET或修改列表/统计。

## 任务化管理维护（2026-11-11）

- 单位位置页使用真实父子树与位置设备联动；位置设备查询包含完整子树。可以从选中位置直接编辑、新增下级、查看设备详情，新增时在表单明确单位，不依赖全局单位预选。
- “移动整个位置”先从后台预览全部位置/设备及快照，再经明确二次确认用理由、版本和幂等键提交。同单位移动保留设备挂载与历史；不执行跨单位整体移交、物理控制或隐式授权。网络结果未知时保持原意图与原键，导航返回可继续；会话/授权单位代数变化清理旧意图。
- 用户“角色/设备范围”读取目标现有范围后，用真实分页设备选择器按名称/编号/地址及位置选择，不再以手填ID为主要操作。勾选当前页只增删本页，跨页选择保留；未知/未加载已有ID不会被刷新静默删除。搜索Enter不提交外层授权表单，变更仍独立理由/版本二次确认，由当前会话授权。
- 设备行“移动位置”直接打开明确设备的本地位置变更，复用既有批量移位事务与履历，不重建档案；保存保留设备列表筛选与页码。
- 桌面树表并列，窄屏纵向布局；设备表内部横向滚动，页级容器不靠隐藏溢出掩盖超宽。权限不足、真实空结果、加载失败和结果未知分别展示。


## SIM到期提醒管理页

[冻结v2合同](<../docs/sim-expiry-reminder-contract.md>)对应独立lazy管理入口；进入页面不自动查询提醒数据，不借人员、设备或旧SIM目录。当前单位仍由服务端逐请求核验。

- read用户只见查询与本人已读；handle用户可处理整轮、显式重开；write用户才见规则、收件范围和显式扫描。配置先明确读取，再逐项填写时区/日历提前量/间隔/重复次数，无业务数字默认值。
- 收件用户以原样平台ID登记；配置、增删范围、扫描、已读、处理/重开都经明确二次确认，由当前会话授权。处理/重开保留理由原文；个人已读与整轮处理不互相代替。
- 成功仅显示原回执并清查询快照，不自动GET。未知写冻结完整意图和原key，只允许沿原操作显式重试；409须成功的明确读取才解锁。403/404清该功能数据，迟到旧owner正文/401不能影响新会话。
- 规范JSON整数、UUID卡ID/opaque设备ID、日历日期、fixed6 UTC时刻和完整分页均严格校验；不替坏响应补假关闭/0/空列表。

## Ubuntu真实浏览器验收

真实Chrome/Chromium与Playwright是可选开发验收工具，不是应用运行依赖。仅Linux浏览器，显式`BROWSER_EXECUTABLE`错误时拒绝，不回退到其它系统或任意引擎。浏览器夹具使用同一Linux工具选择、受控子进程环境和sandbox，不加关闭安全保护的参数。

```bash
bash scripts/prepare-browser.sh
export BROWSER_EXECUTABLE=/usr/bin/google-chrome
python3 scripts/device-groups-smoke.py --browser
```

也可显式下载项目Linux缓存中的Chromium，见[根说明](<../README.md>)。按非root运行；宿主缺少sandbox/共享库时应修复或报告环境，不把关闭sandbox当通过。原390、actor、rawJSON、controlled、时限和业务断言不弱化；Playwright模块统一项目`.tools/browser-tools`，浏览器不得继承私有APP/PG/JAVA/NODE注入。


## 当前真实业务边界

- 管理端与客户端沿用既有权限模型；客户数据只按有效会话及明确本地单位授权读取。海康来源单位不自动成为本地单位，也不自动授予客户访问权。海康设备尚待明确本地归属时，不应显示为客户单位设备或把事件归给测试单位。
- 海康只读轮询可获取设备、历史监测、火警和故障。接口状态不证明在线，轮询接收时间不冒充设备心跳；回调注册和实机上报须独立验证。
- 故障/监测和历史数据以实际来源记录为准。历史快照与历史 `PARAM` 不重复计数，来源单位及数值精度保留。只读取数不代表控制、通知送达或生产部署。

## 海康事件与监测推送

- “事件推送”页展示真实状态与收据。服务端返回的支持/启用消息类型用于显示与配置：980002报警、980004故障、980008监测、980016原生设备事件；现有配置不自动启用新类型。收据状态表示提交解码器进度，不等于业务归属或处理完成。
- 接收端配置仅 integrations:write 可更改，读操作要求 integrations:read。启用类型的变更经明确二次确认并做版本校验；启用报警类型可能创建真实报警并按既有通知规则通知。重新解析仅对 PARTIAL/REJECTED 收据显式提供，使用原收据报文、revision 与 Idempotency-Key；成功只说明已排队，需显式刷新查看实际结果。结果未知时保留同一意图/key重试，或显式刷新后再开启新意图。页面不自动重新处理旧收据。
- 重新解析结果未知时保留原意图和幂等键；只有显式刷新成功才释放旧意图，读取失败不会允许盲目开始新意图。已排队提示不冒充处理完成，列表在刷新前保留上次读取结果。
- 凭据由浏览器安全随机数生成，仅保存前可见；不写浏览器存储、不出现在读取响应或链接导航。请保存前复制完整HTTPS接收地址；轮换会使旧地址立即失效，云订阅不会自动更新。共享URL凭据不是厂商签名，保存配置不等于云端注册。
- 云订阅核对仅在显式点击时请求，只读展示已清洗目标源站；不会创建、修改或删除云订阅。HTTP 200 仅代表服务端已持久化原始收据，不代表业务应用或现场处理。窄屏的收据/订阅表格在内部滚动。
- 故障来源修复状态与来源修复时间独立显示；已修复但无时间时明确显示时间未提供，来源状态未知不推断。来源修复、接收时间及本地人工处置均不代表设备物理火情状态。
- 分项监测上报按指标保留最近已知值，汇总时间不代表各指标同时测得；原始观察时间见历史记录。指标筛选影响当前值与历史表，历史时间筛选只影响历史表。
- 本轮实际浏览器验证覆盖接收类型配置保存、错误密码后重新确认重解析、显式刷新计数、两种故障恢复状态、分项监测精度，以及320/390/1440宽度；均在隔离真实API夹具内执行，未向生产写入测试设备或事件。证据见浏览器验收。
- 联系人在全部授权视图可直接打开新建表单，操作内明确选择所属单位；没有全局单位时不禁用入口，也不默认选择目录中的第一单位。号码只写不读，新建仍默认停用；保存资料不发送通知。
- 设备命令执行入口当前不可用；不展示或承诺模拟命令、模拟成功或真实下行。SIM卡到期提醒是独立台账功能，不是设备模拟或命令能力。
