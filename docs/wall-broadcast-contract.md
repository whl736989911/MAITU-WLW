# N15：值守大屏与浏览器播报（Frozen v1，实施合同）

## 目标与边界

管理端大屏只消费**已验业务接口**（`summary`、`alarms`），不新增业务写路径。

- 刷新间隔与语音播报偏好只保存在**本浏览器**（`localStorage`），默认关闭，可随时停用。
- 浏览器不支持语音、或播报失败时，状态必须**可见**，不静默降级。
- 断线与数据陈旧（超过两个刷新周期）以标签显示。
- `head` 与计数不构成无漏报保证；大屏不是应急联动。

## 界面行为

| 项 | 行为 |
|---|---|
| 指标 | 设备总数 / 在线 / 离线 / 未激活 / 今日报警 / 未处理报警 |
| 数据时间 | 最近一次成功加载时间；超过 `2 × 刷新间隔` 显示"数据已陈旧" |
| 断线 | `navigator.onLine === false` 时显示"断线（浏览器离线）" |
| 语音播报 | 仅播报**新的未处理火警**；同一报警只播一次；可重置 |
| 偏好 | `{sound, refreshSeconds}` 存 `localStorage`；刷新间隔 5..120 秒 |

## 明确不做的

- 不接短信/电话/硬件声光报警器；不做"已播报=已处置"的推断。
- 不把大屏数据缓存到服务端；不吃服务端 head 信号当作无漏报保证。

## 验证

`scripts/dev/n15-ui-proof.sh`（真实浏览器）：指标渲染、数据时间、默认关闭播报、报警列出、启用/停用与偏好持久化（localStorage）。
