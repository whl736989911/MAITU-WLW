# 设备服务与命令合同

## 当前实现与边界

当前代码具有统一设备服务、持久化指令队列、厂商适配、显式回执核对及审计，不再沿用“没有任何真实执行器或入口”的旧阶段说明。产品模型通过标准 HTTPS 网关承载声明的服务；厂商平台通过各自适配器承载已接入的接口，两者使用同一套设备范围、指令状态与历史记录。

存在实现或接口不等于具体设备已完成真实控制验收。只有当前接入配置、型号适用性、能力证据、参数和操作权限均满足要求时才可发起；不得由 HTTP 成功、厂商接受、网关 ACK 或历史模拟记录推导物理执行成功。

队列命令由 worker 外发前会重新核验冻结意图对应的当前操作者、授权 revision、权限及设备范围；核验失败即在发送前阻断。提交时曾有权限不代表排队期间仍有权限。

## 生命周期分工

- 本地资产、位置、产品版本和来源关联分别维护。新增厂商设备先完成云端登记或精确匹配，再显式完成本地验收；返回云端标识不证明终端激活、NS 注册或收到指令。
- 已导入旧台账关联保留原有产品身份和安装关系，须先核对当前来源账号下的精确 EUI、台账 ID；不伪造缺失的产品版本，不自动取查询首行。
- 云台账删除是独立高风险任务，不隐含 NS 注销、终端停机、本地解绑或归档。平台允许对可追溯的最近来源进行显式清理，但历史来源必须属于原账号，不能在切换接入账号后借用旧标识操作新账号资源。
- 本地解绑保留来源代次、原始记录和风险历史；本地归档另行校验未决命令及来源关联，不能把未决结果当成已执行。
- 参数页面默认显示最近保存的快照与观察时间；显式发起读取才能形成新的读取结果，缓存或快照不冒充实时设备状态。

## 状态与证据

| 状态 | 含义 |
|---|---|
| `QUEUED` | 已保存、尚未外发 |
| `IN_FLIGHT` | 已持久化领取，外部请求正在执行 |
| `ACCEPTED` | 厂商或通道接受，具体效果未证实 |
| `UNKNOWN` | 结果不确定，保留核对入口，禁止自动重发 |
| `SUCCEEDED` | 该操作有明确结果证据；读取成功、台账不存在与物理控制完成不可混称 |
| `REJECTED` | 厂商明确拒绝 |
| `FAILED` | 明确失败，或发送前门禁阻断；以尝试记录区分是否发出 |
| `CANCELLED` | 排队任务已取消，未外发 |

旧 TTL 对象式下发记录如果携带 `tx_id`/`txId`，必须与当前命令引用匹配；未匹配的记录不作为本命令接受或执行证据，也不返回他笔载荷。没有标识回显时，保留已记录的精确查询路径合同；厂商/通道 ACK 仍不是终端执行回执。

海康没有可关联到该命令的结果 ID 时，厂商接受或任意后续设备事件都不能证明这条命令已在终端执行；无关联结果不得伪装成终端成功，状态保持 `ACCEPTED` 或 `UNKNOWN` 并按合同核对。

海康云记录删除只按当前操作冻结的来源账号、绑定序列号和云设备 ID 核对，不使用表单参数替换核对对象。缺少核对身份时不得标记删除成功；厂商接受删除不等于云记录已经不可查询。

旧 TTL/TSF 台账删除核对只登录并读取原精确台账 ID，不重新发送删除。只有精确资源查询返回 HTTP 404，或成功 HTTP 响应中的整数业务码 404，才能记录本账号查询范围下的台账不存在；空数据、身份不符、鉴权失败、其他异常均不能推断删除成功。这不证明全局物理设备、NS 或本地资产已注销。

## 权限、来源与实际验收

发起普通服务需要设备服务执行权限；显式核对结果使用查询权限。工程操作仅限管理端，并要求独立工程权限、当前设备范围、操作原因及显式风险确认，不重新输入操作密码。账号、来源代次和目标身份与冻结意图不一致时，不向新来源发送旧意图。

模拟执行器、模拟设备目标及其旧合同已退役；历史命令或审计不能重新解释为真实设备执行证据。测试中的隔离传输夹具不进入生产业务数据，也不作为厂商或终端真实验收。

实际厂商写操作、静音/复位/禁用、物理效果和付费通道仍须具体授权目标及对应真实证据；不得仅为完成清单而触发设备或收费。海康型号 800235/HF-FY500-G 与既有只读发现已在当前方案记录确认，不重复索取已提供的型号和凭据。

资产列表、详情和型号查询将当前绑定海康来源的 `800235` 显示为 `HF-FY500-G`。原始编码 `800235` 仍用于海康入站识别、设备服务能力和命令校验；不转换未绑定海康的设备。

SIM 卡信息及到期提醒是独立真实业务台账，不属于模拟命令执行器；继续按 [SIM 到期提醒合同](sim-expiry-reminder-contract.md) 维护。
