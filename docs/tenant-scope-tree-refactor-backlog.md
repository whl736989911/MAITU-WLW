# 全平台范围与单位/位置树筛选重构（暂缓）

日期：2026-11-04
状态：**暂缓，后续统一开发**

## 用户要求

所有页面默认显示当前账号有权限的全部单位和位置内容，不再强制先选择一个单位。

提供统一的单位-位置树：

- 默认全选
- 可勾选/取消单位或位置
- 列表和统计按勾选范围过滤
- 写操作从当前行或明确目标取单位，不默认落到某个单位

## 当前不符合要求的页面

仍使用 `TenantGate` 或要求单选单位的页面包括：

- 通知资源
- 客户充值设置
- 通知联系人
- 单位通知规则
- 通知屏蔽
- 单位位置
- 单位用户
- 设备分组
- 消息追踪、处理任务、参数覆盖、审计记录等部分页面

## 已支持全平台读取

- 工作台
- 设备监测
- 报警中心
- 值守大屏
- 真实发送记录

## 暂缓原因

后端大量列表接口仍使用：

```sql
WHERE tenant_id = ?
```

只删除前端选择框会导致接口返回 400，必须先改后端数据范围模型。

## 后续实施顺序

1. 新增统一单位-位置树筛选组件
2. 后端列表接口支持全部授权范围
3. 通知与报警页面先改
4. 再改单位、用户、设备分组、位置等页面
5. 写操作从行数据或明确目标取单位
6. 删除 `TenantGate` 作为默认入口

## 当前不处理

本次不继续修改该范围逻辑，保持现状，等待后续统一重构。
